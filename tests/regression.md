# 回归用例沉淀（tests/）

本目录是索骥（sop-retrieval-mcp）核心模块的回归测试载体。每次改动
（分块、检索、登记库、版本冲突、试用闸）之后，回归测试必须全绿方可提交：

```bash
python3 -m unittest discover -s tests -t .    # 仓库根目录下运行
```

范围说明：本套件纯标准库，覆盖 `sop_mcp` 内核（chunking/versions/retrieval/store/trial）；
`e2e_test.py`（MCP 协议端到端）与二进制格式解析依赖 `mcp/docx/pypdf`，不在干净环境回归范围。

## 回归铁律

1. **防篡改指纹回归**：`test_防篡改指纹现形` 永不删除——文件改动必须经指纹重索引，静默替换不允许；
2. **重复摄取跳过回归**：未改动的文件按 sha256 指纹跳过，保证幂等；
3. **持久化重建回归**：manifest 重建后检索结果必须一致；
4. 新增行为先加回归用例再改实现（红→绿）。
